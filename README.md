## How it works

`main.ts` (Node, standard library only) copies the finished image
`entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`) and
checks the copy is a whole PNG before exiting. The program runs offline and
deterministically: two runs produce byte-identical output.
